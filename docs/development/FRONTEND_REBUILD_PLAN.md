# 前端重建方案（2026-09-13）

## 背景

原测试版前端（Next.js Pages Router + 45+ 组件）信息架构散乱：同一局游戏被拆成十几个平行入口（顶部栏 / DockBar / 侧栏 / 复盘弹窗 / 回看 / 收藏 / 手记 / 回忆 / 语音输入），操作路径长且不一致，属于"多功能工作台"而非"沉浸式推理游戏"。已于 `b618c44` 整体移除，本方案为重建依据。

## 已确认决策

| 项 | 决策 |
| --- | --- |
| 目标端 | **Web 端优先**，暂不考虑手机 |
| 风格 | **纯午夜风（更冷峻）**：沿用 DESIGN.md 的深色 + 发丝边框 + 酸柠绿，但不用宋体 |
| 中文 | **全用黑体**（思源黑体 Noto Sans SC + 系统黑体回退） |
| 结构 | **三幕合并**（阅读 → 调查 → 终局）进度表达 |
| 范围 | **P0–P5 全部完成**（含管理后台） |

## 设计概念：午夜卷宗（The Living Case File）

游戏界面是一份**正在实时书写的案卷**：

- **叙事流** = 案卷正文，每个 AI 发言是一条"证词条目"（编号 + 时间戳 + 角色名）
- **线索 / 证据 / 回忆 / 手记** = 案卷附件，收进可收起的**档案抽屉**
- **酸柠绿 `#e4f222`** 是"侦探的高亮笔"，只标记：当前主行动、刚解锁的线索、当前阶段
- 深色分层 + 0.5px 发丝边框 = 深夜档案室的精确感

## 信息架构

玩家侧 3 页，管理侧收拢为 1 个后台：

```
玩家侧
├─ /            首页：最近一局 · 开始新游戏 · 我的记录
├─ /play        游戏主界面（唯一游戏入口）
└─ /records     我的记录（历史局 + 复盘，只读）
管理侧
└─ /admin       剧本工作台：导入 · 审核 · 发布 · 编译任务 · 来源核验
```

## 游戏主界面：三段式房间

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部·阶段刻度：阅读 ▸ 调查 ▸ 终局     （当前：调查 · 剩余2点）    │
│          [🗂 档案]   [回看上一轮]   [退出本局]                    │
├───────────────────────────────┬──────────────────────────────┤
│                               │  档案抽屉（右侧，可收起/展开）      │
│   【叙事流 · 案卷正文】          │   ┌ 角色档案（4 人卡）           │
│                               │   ├ 线索·证据（已解锁 7）         │
│  #07 顾二：                   │   ├ 回忆（3 条）                │
│  「那天夜里我确实不在书房……」    │   ├ 手记（我的笔记）            │
│  #08 你：                     │   └ 本轮议题                    │
│  「那你当时在哪？」            │                              │
├───────────────────────────────┴──────────────────────────────┤
│ 底部·行动条（当前阶段唯一主行动，其余收进「…」）                      │
│   [🔍 调查书房]   [💬 公开讨论]   [📞 私聊唐小姐]   [❓ 提问]       │
└──────────────────────────────────────────────────────────────┘
```

**三条原则**（解决"操作麻烦"）：
1. **单一主行动**：底部行动条只给当前阶段最该做的 1 个高亮动作 + 2–3 个次要动作，其余收进"…"。
2. **档案抽屉**：线索/证据/回忆/手记/角色卡全部收进右侧抽屉，叙事流保持纯净。
3. **阶段刻度**：后端多阶段视觉合并为 3 幕，顶部一根进度条讲清"我在哪、还剩什么"。

## 风格：保留与调整

| 保留（DESIGN.md） | 调整 |
| --- | --- |
| 深色底 `#08090a` + 分层表面 | 不变 |
| 0.5px 发丝边框、6/12px 圆角、字重上限（不粗体） | 不变 |
| 酸柠绿 `#e4f222` | 从"按钮色"改为"高亮笔"：只标当前主行动 / 新线索 / 当前阶段 |

## 字体（全黑体）

| 用途 | 字体 | 说明 |
| --- | --- | --- |
| 叙事正文 + 界面 | **思源黑体 Noto Sans SC** | 中文黑体，字重 400/500/600（600 为上限） |
| 拉丁 UI / 数字 | **Inter**（variable） | 延续午夜风精确感 |
| 编号 / 时间戳 / 元数据 | **JetBrains Mono** | 档案编号气质 |

落地：next/font/google 自托管 + unicode-range 按需分片 + `font-display: swap` + 系统黑体回退（PingFang SC / Microsoft YaHei / Noto Sans CJK）。

## 技术栈

Next.js 16（App Router）+ React 19 + Tailwind CSS v4 + Zustand + Radix UI（按需）+ lucide-react + axios。版本对齐原 `frontend/package.json`（已在原环境构建通过）。

## 分阶段计划

| 阶段 | 内容 | 交付物 |
| --- | --- | --- |
| **P0 脚手架** | Next.js 16 App Router + Tailwind v4 + 字体 + 设计 token 落地 | 空壳可跑、样式地基 |
| **P1 游戏房间骨架** | 三段式布局 + 阶段刻度 + 档案抽屉 + 行动条 | 主界面静态可点看 |
| **P2 各阶段操作** | 调查/讨论/私聊/提问/分享/回忆/手记 接入后端 | 完整可玩一局 |
| **P3 终局** | 投票、封卷、结算、复盘 | 整局闭环 |
| **P4 首页 + 记录** | 首页、历史记录 | 玩家侧完成 |
| **P5 管理后台** | 导入/审核/发布工作台 | 全部完成 |
