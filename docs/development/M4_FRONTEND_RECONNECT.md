# M4 新版前端接回与本机验证

日期：2026-09-16。状态：核心玩家流程修复与合成验证完成，真实商业本及用户体验尚未验收。

## 本轮目标

恢复本地依赖，修复新版前端与已有后端的契约断点，提供选角、授权材料、阶段推进、调查、交流、封卷和结局的真实数据流程。用隔离虚构资料验证一局及刷新恢复，再独立复核。

## 范围与边界

- 保留现有设计与后端规则；不改商业剧本、角色权限、评分或旧事件。
- 不用演示资料填充真实游戏；演示与真实请求明确区分。
- 操作按后端返回的权限和阶段开放；失败保留输入，不自动重发未知模型请求。
- 测试仅使用独立本机数据和模拟模型，不产生云模型费用，不部署公开服务。
- 当前目录没有真实 `.env`、商业资料或旧局。用户已被询问资料位置；缺失时只报告合成测试结果，不能宣布商业本、真实模型或手机已验收。
- 后台管理完整编辑、语音/TTS和公开部署不属于本次玩家整局修复。

## 完成条件与验证

1. 新局明确选择故事和角色，继续旧局不新建局或更换用户。
2. 正式页面只呈现服务器授权数据，失败有明确提示。
3. 推进/结算不发送禁止的 null target；调查选择、交流及封卷使用各自真实契约。
4. 一次性操作防连点，未知结果可刷新核对，草稿不在失败时丢失。
5. 前端检查、生产构建、行为回归；后端安全套件、预检自测和 diff 检查。
6. 本机实际 HTTP + 页面完整流程/刷新验证；独立只读复审。

## 已完成的修复

- 用锁文件恢复后端虚拟环境和前端依赖，未更换框架或新增运行依赖。
- 新游戏由玩家明确选故事、选角色；继续游戏读取原局，不自动选择第一个角色或创建替代存档。修复从记录页开始新游戏时被旧页面状态跳回上一局的问题。
- 恢复后端实际投影类型，按服务端阶段、授权资料与可用动作展示；真实页面空记录保持为空，不混入演示对白。回忆读取 `memories.entries`。
- 推进、结算省略后端禁止的 `target: null`；调查使用真实地点/扣点契约，角色提问使用服务器允许的有限议题，私聊按通话权限进入和结束。
- 接回终局指认、信任、私密问卷、最大选择数与封卷确认；各 AI 席位独立提交，五席封卷后才能结算。得分、真相与投票公示使用服务器结果。
- 提交前保存原请求标识；连点只发送一次。网络结果不明或 HTTP 200 仍待定时保留原请求，只在明确点击核对时复用原标识。没有本地副本时，可按服务端已保存的待定回执核对。
- 切换登录身份时清除旧资料，拦截迟到的成功/失败响应；首页和记录页复用现有身份，支持错误重试及分页读取。
- 接回授权档案、已获回忆、按身份/局/角色隔离的本地手记，以及只读阶段回看。公开和私聊草稿分开保存。
- 修复测试入口对已删除 `tests/media_safety` 的硬依赖；三个必需安全套件仍须存在，未通过跳过必需套件掩盖失败。

### 实际 HTTP 整局

新增 `backend/scripts/local_play_validation.py`：绑定本机回环地址，使用独立临时 SQLite、虚构五角色资料、本地模拟模型；禁止外连，不读取真实 dotenv。模拟身份和发布准备仅用于联调，实际玩法仍经过现有 HTTP 路由、服务、规则、存储与授权投影。

五种真人选角分别完成公开/私聊、阶段推进、调查、五席封卷、结算与恢复。数据库路径禁止覆盖已有文件；正常关闭后清理临时数据。此验证不覆盖真实登录、后台内容发布或云模型行为。

### 实际浏览器

通过 Ego Browser 在本机前后端完成以下操作：

1. 角色 a 开场、阅读、两轮调查、公开有限议题、角色 c 私聊及结束通话；到终局提交并逐席封卷，查看结局。
2. 多选题选满两项后第三项禁选；五席封卷后结算，自己的得分、真相及五席实际投票可读。
3. 刷新同一结局地址后，主区域文本一致；档案只显示本人授权资料。手记保存后关闭/重开仍在，关闭回到档案按钮。
4. 390px 竖屏下，档案和调查页面的文档宽度均为 390px，没有横向溢出。这是桌面浏览器模拟尺寸，未代替实体手机验收。
5. 首页与记录页恢复旧局；从记录页重新开始能进入选角。角色 b 的开场刷新保留 b，并创建与 a 不同的新局。
6. 角色 b 阅读推进时模拟断网：按钮锁定、保留原请求；恢复网络后刷新仍停留原阶段且不自动提交，原请求标识一致。明确核对后进入调查，待定记录清除。

浏览器完成一局、另一角色完成选角/刷新/断网恢复；没有把 HTTP 五角色整局写成浏览器五角色验收。模拟终局看法可因内容检查失败而留空，不能据此判断真实推理质量。

**本轮真实模型/ASR 调用 0 次，真实云费用 ¥0。** 模拟账本中的数值是测试数据。未读取或改写旧商业本、真实存档；本目录当前没有它们。
