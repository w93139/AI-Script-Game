# 角色回答：试玩验收清单

本轮检查“问角色后能否得到与资料一致的回答”。不用懂代码。

**当前状态（2026-09-18来历复验）：6条新真实回答全部运行及独立来源核对通过，本机入口已恢复，可以开始本轮试玩。Key正常，无需重贴。请用新局测试新版按题回答；旧局和旧失败保持。当前仍属M4专项验收，不代表终局或五角色完整语义都已通过。**

原局仍可看资料、采用已有资料简答；这些操作不等于验收了本次新 AI 回答要求。

## 怎么开始

1. 打开 http://127.0.0.1:3017/，刷新页面。
2. 继续原局。原先已经失败的问题保留原结果，可以点“使用资料简答，继续游戏”；它不算修复后的 AI 回答测试。
3. 新版按题回答需要新局；旧局已绑定的模型和失败记录保留。请另开一局选择唐小姐，进入第一阶段调查，调查“书房·角落”取得相关线索后，选择“失物与衣服口袋”。原局会保留在记录中。

## 逐项检查

| 要做的事 | 通过标准 |
| --- | --- |
| 公开问阿杰“先问失物” | 角色正面回答钱数与衣物的对应关系；有完整回答，不是只有红字、空白或反问同一个问题。 |
| 再问“追问钱的来处” | 回答说明与自己做工、积攒有关；不凭空添加转账、寄钱、已经交付等经历。 |
| 问“核对证据范围” | 能区分已知线索与不知道的经过，不仅凭钱在口袋里就断定谁移动衣服、具体时间。 |
| 单独对话中问一个尚未用过的问题 | 对方有回应；这条私聊不出现在公开发言记录中。公开和私聊共用提问次数，问过的问题不会在另一处重新开放。 |
| 向另外两位角色各问一个问题 | 回答对应当前角色和问题，不把别人说过的事写成自己亲眼看见；不提前揭晓未取得的剧情。 |
| 刷新页面、返回首页再继续 | 仍是原角色、原进度；已保存回答保持，不自动再生成一遍。 |
| 结束单独对话后调查、继续下一阶段 | 调查地点和推进按钮按当前条件可用，不因之前一条回答失败一直锁住。 |

**内容判断原则：**时间、人物、钱数和动作不能与当前已读资料冲突；“听说”“可能”“不知道”不能变成无依据的确定结论。无需你独自核对隐藏剧情，开发测试会负责逐条来源核验。

## 什么情况不算通过

- 只有格式检查通过，但内容说错。
- 用资料简答完成了流程，却把它算成 AI 正常回答。
- 重复点击多次才偶然成功，或刷新后答案、阶段变了。
- 有一项失败就把问题记下来；不用反复发送同一道题。

## 发现问题时发给我什么

截图加一句话即可：**“我选了谁／第几阶段／问了什么／哪里不对”**。最好保留游戏地址和当前局，不要发送 API Key。
