## 视觉落地

- 以 `#08090a` 画布、`#0f1011` 卡片、`#161718` 浮层、`#23252a`/`#383b3f` 边框、`#d0d6e0` 正文构成层级。`#e4f222` 用于主要推进操作；工具、角色选择、滚动条和头像使用灰白色。
- Inter 经 Next 字体变量接入正文、标题和弹窗；中文沿用系统黑体。中文首页标题使用 400，次标题与按钮使用 500，避免非可变中文字体将 510 匹配为过重字形。强调文字最高 590，编号保留等宽栈。
- 首页采用大标题、最近一局横向卡片、故事目录行；手机最近一局自然折为纵向，继续按钮撑满卡片宽度。仅最近一局的继续入口使用荧光填充。
- 阅读正文 16px / 1.85，段落限制最大行长，标题不再继承大段正文间距。线索叠卡保留横向浏览和内部滚动，改为 12px 圆角、灰白边框。
- 角色选项用明确描边、勾选符号和灰白底显示选中；按钮/输入圆角 6px，主要玩家操作保留 44px 点击区域，输入框 16px 避免手机聚焦缩放。
- 首页 240ms 轻微进入、按钮箭头 160ms 位移；减少动态偏好关闭这些动画。键盘焦点、Esc 关闭与原有草稿交互保留。
