# M4 调查、交流与推进恢复

日期：2026-09-17。状态：本机界面已更新，等待用户复测。本轮仅调整前端交互与提示，不改变调查、通话、角色权限或模型契约。

## 用户问题与核查

用户反馈调查地点无法勾选、与角色交流没有回复、找不到下一幕入口。只读核查原局显示：第一阶段调查，剩余22点；与舒望的单独对话仍在进行；一条自由私聊已保存，但没有提交有限议题或发起模型请求。不存在本次API失败或模型扣费。

- 通话进行时，后端明确禁止调查与推进。旧页面禁用了控件，没有显示原因。
- 单人模式的自由发言只记录玩家说法；AI回应须走服务器允许的议题。旧页面的“发送私聊”文案容易被理解为已请求回答。
- 该进度下舒望没有可问的议题。旧下拉框为空，没有解释；其他角色仍有可用议题。

## 本轮改动

1. 调查区显示私聊阻塞原因，提供“结束对话，恢复调查”。仍使用原STOP_CALL，不绕过规则。
2. 顶栏常驻“下一阶段”定位入口，回看状态下先返回当前进度。推进区解释未满足的条件；有剩余点数时，先提示再由玩家确认提前结束。
3. 提问区放到交流区前方，说明当前可问问题、暂无问题及继续调查的路径。自由输入改为“记录公开发言 / 记录单独发言”，明确不会自动请求回答。
4. 一次明确点击“发送问题并等待回应”，先保存ASK_TOPIC，再以服务器返回的冻结reply_request发出一次回答请求。绑定本次保存key/sequence、账号、游戏、阶段、角色、频道、通话及revision。
5. 刷新、换号、换局、未确认请求及模型不可用不会自动重发；原请求核对和显式有源简答继续保留。等待和错误在交流区就近显示。
6. 同一轮重复致电被规则拒绝时，提示先选择其他角色，不再仅提示刷新。
